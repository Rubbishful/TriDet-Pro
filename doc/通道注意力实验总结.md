# 通道注意力实验总结

## 1. 背景与动机

SENet 提出 Squeeze-and-Excitation (SE) 通道注意力后在图像分类和目标检测中取得了稳定提升。在 TriDet 时序动作检测基线上引入 SE，目标是验证通道注意力能否帮助模型学习更有判别力的时间特征表示。

### 实验演进路线

```
无 SE baseline (68.59%)
  → fusion 位置 + r=16      (67.26%, SE 退化)
    → pre_fusion 位置 + r=16  (68.34%, 基本消除负影响)
      → pre_fusion 位置 + r=4 (66.77%, 容量增加反而变差)
```

每次改动只改变一个变量：第一次改位置（fusion → pre_fusion），第二次改容量（r=16 → r=4）。以下逐次展开。

---

## 2. 实验设计

### 2.1 实验一：fusion 位置，r=16

| 参数 | 值 |
|---|---|
| `att_position` | `fusion` (5 分支融合 + DropPath 残差后) |
| `att_reduction` | 16 (bottleneck = 512/16 = 32) |
| `batch_size` | 4 |
| `learning_rate` | 1e-4 |
| 训练轮次 | 69 epochs (best @ 60) |

**预期**: SE 在通道上学习差异化权重，抑制噪声通道、增强信息通道，mAP 应高于 baseline 68.59%。

**实际**: 最佳 mAP 67.26%，比 baseline 低 **1.33%**。SE 没有帮助，反而有害。

### 2.2 实验二：pre_fusion 位置，r=16

| 参数 | 值 |
|---|---|
| `att_position` | `pre_fusion` (LayerNorm 后、5 分支 split 前) |
| `att_reduction` | 16 |
| `batch_size` | 8 (显存利用率 ~40%，翻倍利用) |
| `learning_rate` | 2e-4 (线性缩放) |
| 训练轮次 | 69 epochs (best @ 55) |

**改动理由**: fusion 位置在 `x + drop_path(融合)` 残差连接之后，identity 路径主导信号，SE 输入缺乏通道间差异性。pre_fusion 将 SE 移到 LayerNorm 输出处，此时特征干净、通道间差异大，给 SE 更好的"原材料"。

**实际**: 最佳 mAP 68.34%，仅比 baseline 低 **0.25%**。位置改动有效 — SE 不再有害，方差翻倍（branch std 0.03→0.11），但注意力仍弱（极端通道 ~0%）。

### 2.3 实验三：pre_fusion 位置，r=4

| 参数 | 值 |
|---|---|
| `att_position` | `pre_fusion` |
| `att_reduction` | **4** (bottleneck = 512/4 = 128) |
| `batch_size` | 8 |
| `learning_rate` | 2e-4 |
| 训练轮次 | 69 epochs (best @ 69) |

**改动理由**: r=16 时 bottleneck 仅 32 维，需编码 512 个通道的相互关系到 32 个数值，信息压缩过于激进（93.75%）。r=4 将 bottleneck 扩到 128 维（75% 压缩），期望 SE 有足够的表示容量学习有意义的通道重要性。参数从每层 33K 增至 132K，7 层总计约 0.92M（相对模型 ~30M 总量增加约 3%）。

**实际**: 最佳 mAP 66.77%，比 r=16 **下降 1.57%**，比 baseline 低 1.82%。更大容量没有带来更好的注意力，反而引入了有害的系统性偏差。

### 3.3 关键观察

1. **fusion → pre_fusion 是有效改进**: mAP 从 67.26% 提升到 68.34%，接近 baseline，确认位置是关键瓶颈
2. **r=16 → r=4 是错误方向**: 所有 epoch 的 mAP 均显著低于 r=16，收敛也更慢（epoch 5 仅 0.46% vs 1.97%）
3. **所有 SE 变体均未超越 baseline**: 三次实验中无一超过 68.59%，通道注意力对 THUMOS14 + TriDet 组合的增益为负或近似零

## 4. 注意力权重诊断

使用 `tools/inspect_se_weights.py` 对三个 checkpoint 进行静态参数 + Runtime Hook 双重检查。

### 4.1 Static 参数检查

三组实验的 SE 权重在静态层面**几乎没有差异**：

| 参数 | fusion r16 (ep69) | pre_fusion r16 (ep55) | pre_fusion r4 (ep69) |
|---|---|---|---|
| fc.1.weight mean | ~0.0002 | ~0.0003 | ~0.0004 |
| fc.1.weight std | 0.0258 | 0.0260 | 0.0260 |
| fc.3.weight mean | ~-0.0010 | ~0.0007 | ~0.0014 |
| fc.3.weight std | 0.1019 | 0.1020 | **0.0511** |
| fc.1.bias mean | ~0.0030 | ~0.0024 | ~0.0028 |
| fc.3.bias mean | ~-0.0010 | ~0.0017 | ~0.0014 |

唯一的明显变化是 r=4 的 fc.3.weight std 从 0.102 降到了 0.051 — 这是预期行为，因为 excitation 矩阵从 `[512, 32]` 变为 `[512, 128]`，同样的梯度分配到更多参数上，每个权重的更新幅度变小。

| 对应 mAP | 67.26% | 68.34% | 66.77% | — |

### 4.4 综合解读

**fusion 阶段**: SE 完全退化。权重 mean 精确卡在 0.498–0.499，std 极小（branch <0.06），所有通道被平等对待。融合后的 `x + drop_path(out)` 残差连接使 identity 路径主导，SE 输入几乎不含通道间差异，梯度信号为零 → Sigmoid 输出卡在 0.5。

**pre_fusion r16 阶段**: 位置前移让 SE 面对 LayerNorm 输出，通道差异增大，方差翻倍。stem.1 出现约 4% 的极端通道（~20/512），说明靠近输入端的 SE 层可以学到轻微的通道偏好。但 96% 的通道权重仍在 0.5 附近 — 注意力远未达到"有效"水平（通常需要 10-30% 的极端值）。

**pre_fusion r4 阶段**: bottleneck 从 32 扩到 128 后，SE 有了更大的参数空间，但它用这些自由度做了错误的事——mean 从 0.503 偏移到 0.522，branch.0 和 branch.2 的 std 继续增大到 0.17–0.19，但在 branch.0 的 2.9% >0.9 增强出现的同时，mAP 反而下降了 1.57%。说明这些"学到的"通道增强是**噪声而非有意义的选择**，系统性放大了不该放大的通道，破坏了预训练特征的平衡。

**核心矛盾**: 时序动作检测的 loss（分类 + 回归，作用于 FPN 输出层级）对"每个通道该放大还是抑制"提供的梯度信号太弱太间接。SE 需要通过两条 FC 层反传梯度，链路长、信号衰减严重，无论怎么调整位置或容量都无法获得足够的学习信号。

## 5. 技术要点

### 5.1 SELayer 实现

```python
class SELayer(nn.Module):
    def __init__(self, channels, reduction=16):
        self.fc = nn.Sequential(
            nn.AdaptiveAvgPool1d(1),           # (B,C,T) → (B,C,1)
            nn.Conv1d(channels, channels//r, 1),  # Squeeze
            nn.ReLU(inplace=True),
            nn.Conv1d(channels//r, channels, 1),  # Excitation
            nn.Sigmoid()
        )
    def forward(self, x):
        return x * self.fc(x)
```

两个 kernel_size=1 的 Conv1d 等价于全连接层，在通道维度上做压缩-重建。时间维度已由 AdaptiveAvgPool1d 压缩为 1。

### 5.2 reduction 与参数量

```
C=512 channels:

  r=16 → bottleneck=32,  parameters=33K/layer, 7 layers=233K
  r=4  → bottleneck=128, parameters=132K/layer, 7 layers=923K
```

### 5.3 ECA 备选

ECALayer 用单个 1D conv 跨通道滑动代替两个 FC 层，仅 3 个参数（kernel_size=3），是 SE 的轻量替代方案。在 SGPBlock 中已实现但尚未训练测试。

### 5.4 预训练特征的价值

TriDet 使用 I3D 预训练特征（Kinetics），这些特征已经过充分的通道级优化。不加区分地重新标定 512 个通道很可能破坏预训练学到的精细平衡。这是 SE 对 TriDet 无效的一个潜在解释，也提示如果要用通道注意力，可能需要配合特征层面的微调策略（如逐步解冻、降低 SE 学习率等）。

---

## 6. 结论

### 三个核心发现

1. **位置决定生死**: fusion 位置 SE 完全退化（权重 ≈0.5），pre_fusion 能恢复信号质量。如果在错误的残差后位置插入注意力，无论怎么调参数都是徒劳。

2. **容量不是瓶颈**: r=4 给了 SE 4 倍参数，bottleneck 从 32 扩到 128，但 mAP 不升反降。TAD loss 对通道注意力的梯度信号太弱，更大的参数空间反而引入了噪声。

3. **通道注意力对 THUMOS14 + TriDet 组合无效**: 三次实验最优结果 68.34%（-0.25% vs baseline），均未超越无 SE 的 68.59%。通道注意力在这个任务-架构组合上不提供增益。

### 后续方向建议

| 方向 | 理由 | 优先级 |
|---|---|---|
| 回退到 baseline | 68.59%，三次实验最佳结果，简洁可靠 | **推荐** |
| 尝试 ECA | 仅 3 参数，归纳偏置完全不同（跨通道卷积 vs FC 压缩），值得一次实验排除整个通道注意力路线 | 可选 |
| 转向其他改进 | BiFPN、特征增强、多层特征融合等对 TAD 更直接有效的方向 | **主要精力** |
| 如果坚持 SE | 需要配合针对性训练策略：独立 SE 学习率、渐进式 warmup、或先固定预训练层只训练 SE 的阶段性训练 | 低优先 |

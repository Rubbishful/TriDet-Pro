                   │

### 4.2 A1: Trident-head → 普通回归头 (已完成 ✓)

**科学问题**: 离散化边界回归是否优于直接连续回归？

**原理**:

- **Trident-head**: 将边界回归拆解为 17 个 bin 的离散化分类 + 期望值还原
  - 中心偏移头: `2×(num_bins+1)=34` 通道 (左右各 17 bin)
  - 左右边界头: 各 17 通道分类得分
  - 三路输出 → softmax → 期望公式 → 连续偏移量

- **普通回归头**: 直接输出 2 通道 (左偏移, 右偏移) 连续值

**配置覆写**:
```yaml
model:
  use_trident_head: false
```

**预期**: mAP@0.7 下降最明显 (离散化对精确定位帮助最大), avg_mAP -2~4%

**脚本定义**: [run_ablation.py:30-32](evaluate/run_ablation.py#L30-L32) → `ABLATIONS['A1']`

### 4.3 A2: SGP Backbone → Conv Backbone (已完成 ✓)

**科学问题**: SGP 的 5 分支多尺度感知对性能贡献有多大？

**原理**:

- **SGPBlock** 包含 5 个并行分支, 数学形式: `out = fc × phi + (convw + convkw) × psi + x`
  - `psi` (depthwise_conv k3) — 即时局部特征
  - `fc` (pointwise 1×1) — 逐通道线性投影
  - `convw` (depthwise_conv k3) — 标准感受野
  - `convkw` (depthwise_conv `round((k+1)×win_size)`) — 扩展感受野
  - `global_fc` (1×1→avgpool→relu→1×1) — 全局通道门控
  - 全部分支用深度可分离卷积, SGP 总参数不到 3M

- **ConvBackbone**: 仅堆叠标准 ConvBlock (Conv1D + GELU + LayerNorm), 无多尺度融合

**配置覆写**:
```yaml
model:
  backbone_type: conv
```

**预期**: **影响最大的消融项**, avg_mAP -5~7%

**脚本定义**: [run_ablation.py:33-35](evaluate/run_ablation.py#L33-L35) → `ABLATIONS['A2']`

### 4.4 A3: SGP 窗口尺寸消融

**科学问题**: `convw` 和 `convkw` 的卷积核尺寸如何影响多尺度特征提取？

**原理**:
- `n_sgp_win_size` 控制 `convkw` (大窗口分支) 的核大小: `kernel = round((win_size+1) × k)`
- 默认值 `1` 表示最紧凑窗口。增大窗口 → 更长时序依赖, 但计算量增加
- 可为每层 FPN 设置不同大小: `n_sgp_win_size` 可以是 list

**配置覆写** (各子实验):

**预期**: 存在最优窗口值, 过小 → 感受野不足, 过大 → 噪声引入

### 4.5 A4: SGP 的 k 参数消融

**科学问题**: 大窗口分支 `convkw` 的扩展比例敏感度如何？

**原理**:
- `k` 控制 `convkw` 核大小: `kernel_size = round((n_sgp_win_size+1) × k)`
- k 越大 → 感受野越大 → 更长时序依赖, 但引入更多噪声

**k 与 kernel_size 的关系** (默认 `n_sgp_win_size=1`):
```
k=1.0 → kernel=round(2×1.0)=2    k=1.5 → kernel=round(2×1.5)=3
k=3.0 → kernel=round(2×3.0)=6    k=5.0 → kernel=round(2×5.0)=10  (基线)
k=7.0 → kernel=round(2×7.0)=14
```

**配置覆写** (各子实验):
```yaml
# A4_k1.0
model: { k: 1.0 }

# A4_k1.5
model: { k: 1.5 }

# A4_k3.0
model: { k: 3.0 }

# A4_k5.0 (基线)
model: { k: 5.0 }

# A4_k7.0
model: { k: 7.0 }
```

**预期**: k=1.5~5.0 为 optimal 区间, 过大或过小退化

**脚本定义**: [run_ablation.py:41-51](evaluate/run_ablation.py#L41-L51) → `ABLATIONS['A4_k1']` / `A4_k3` / `A4_k7`

### 4.6 A5: DIoU → GIoU 损失

**科学问题**: 1D 时序检测中 GIoU 退化为 IoU, DIoU 的优势有多大？

**原理** (详见[第七节 7.5](#75-diou-vs-giou)):

- **DIoU Loss** = `1 - IoU + ρ² / c²`
  - `ρ` = 预测中心到 GT 中心的距离, `c` = 最小外接段长度
  - 中心距离惩罚 → 方向性引导, 收敛更快

- **GIoU Loss (1D 退化)** = `1 - IoU + (C-U)/C`
  - 在 1D 中, 最小外接段 C = 并集 U → `(C-U)/C = 0`
  - **GIoU 完全退化为 IoU**, 丢失距离信息！

**配置覆写**: 此项标记为 `manual`, 需修改源码

在 [meta_archs.py:946](libs/modeling/meta_archs.py#L946) 附近:
```python
# 修改前 (基线)
reg_loss = ctr_diou_loss_1d(pred_offsets, gt_offsets, reduction='sum')

# 修改后 (A5)
reg_loss = ctr_giou_loss_1d(pred_offsets, gt_offsets, reduction='sum')
```

**预期**: DIoU > GIoU, 高 tIoU 阈值差异更明显

**脚本定义**: [run_ablation.py:53-56](evaluate/run_ablation.py#L53-L56) → `ABLATIONS['A5']` (manual=True)

### 4.7 A6: FPN vs Identity Neck

**科学问题**: SGP 的全局门控已提供跨尺度信息, FPN 融合是否冗余？

**原理**:
- **Identity Neck** (TriDet 默认): FPN 各层独立处理, 不做跨层融合
- **FPN**: 标准特征金字塔, 自顶向下 + 横向连接
- SGPBlock 的 `global_fc` 门控已提供跨尺度信息整合, 额外 FPN 可能冗余

### 4.8 A7: 中心采样半径消融

**科学问题**: 正样本分配策略中, 中心采样半径多大最优？

**原理** (详见[第七节 7.1](#71-center_sampleradius)):

中心采样机制 ([meta_archs.py:595-614](libs/modeling/meta_archs.py#L595-L614)):
```
GT 段中心区域 = [center - stride × radius, center + stride × radius]
仅落在此范围内的 anchor 点才是正样本
```

- `radius=0.0` → 仅 GT 段严格中心点是正样本 (极严格)
- `radius=1.5` → 基线值, 排除边界模糊点
- `radius` 越大 → 正样本越多但可能引入边界噪声

**配置覆写** (各子实验):
```yaml
# A7_r0.0
train_cfg: { center_sample_radius: 0.0 }

# A7_r0.5
train_cfg: { center_sample_radius: 0.5 }

# A7_r1.0
train_cfg: { center_sample_radius: 1.0 }

# A7_r1.5 (基线)
train_cfg: { center_sample_radius: 1.5 }

# A7_r2.0
train_cfg: { center_sample_radius: 2.0 }
```

**预期**: radius=1.0~1.5 最优, radius=0.0 因正样本过少下降, radius=2.0 引入边界噪声

**脚本定义**: [run_ablation.py:62-67](evaluate/run_ablation.py#L62-L67) → `ABLATIONS['A7_r0']` / `A7_r1`

### 4.9 A8: 分类损失权重消融

**科学问题**: 分类与回归损失的最优权重比？

**原理**:
- TriDet 总损失 = `loss_weight × cls_loss + reg_loss`
- `cls_loss` = sigmoid focal loss (BCE + α=0.25, γ=2.0)
- `reg_loss` = DIoU loss (仅正样本)
- 默认 `loss_weight = 1.0` (等权重)

**配置覆写** (各子实验):
```yaml
# A8_lw0.5
train_cfg: { loss_weight: 0.5 }

# A8_lw1.0 (基线)
train_cfg: { loss_weight: 1.0 }

# A8_lw2.0
train_cfg: { loss_weight: 2.0 }

# A8_lw5.0
train_cfg: { loss_weight: 5.0 }
```

## 六、分析维度与方法

### 6.1 时长分层分析

**目的**: 评估模型对不同时长动作的检测能力差异

**分层标准**:
| 分组 | 时长范围 | 典型动作 |
|------|---------|---------|
| Short (<2s) | < 2s | 跳跃、投掷 (瞬时动作) |
| Medium (2-10s) | 2-10s | 游泳、跑步 (中等持续) |
| Long (>10s) | > 10s | 举重、演讲 (长时动作) |

**评估指标**: Recall @ tIoU=0.5 (预测段与 GT 段匹配率, 需类别一致)

**方法**: 遍历 GT 实例 → 按 `(end - start)` 分桶 → 对每个预测, 在对应 GT 中找最佳 tIoU 匹配

### 6.2 密度分层分析

**目的**: 评估视频中动作密度对检测精度的影响

**分层标准**:
| 分组 | 每视频 GT 数 |
|------|-------------|
| 稀疏 | 1-3 |
| 中等 | 4-6 |
| 密集 | 7-10 |
| 超密集 | > 10 |

**评估指标**: 平均匹配率 (简化 AP, tIoU@0.5)

**注意**: 密集场景中, 多个动作段重叠/邻近可能导致 NMS 过度抑制

### 6.3 混淆矩阵分析

**方法**:
1. 对每个预测段, 找最佳匹配 GT 段 (tIoU ≥ 0.5, label 一致)
2. `cm[gt_label, pred_label] += 1`
3. 行归一化: `cm_norm[i,j] = cm[i,j] / Σⱼ cm[i,j]`
4. 输出 Top-K 误分类对 + 热力图

### 6.4 消融对比可视化

**mAP vs tIoU 曲线**: 横轴 tIoU (0.3→0.7), 纵轴 mAP, 不同颜色 = 不同实验

- Trident-head 优势在**高 tIoU** 更明显 (离散化 → 边界更精确)
- SGP 优势在**全 tIoU 范围**均匀 (特征判别力全面改善)

**组件贡献堆叠图**: 柱状图 + 差异标注, 直观展示每个组件移除后的性能下降

## 七、设计决策分析

> 详细分析见 [evaluate/design_analysis.md](evaluate/design_analysis.md), 此处摘要核心要点。

### 7.1 center_sample='radius'

**代码**: [meta_archs.py:595-614](libs/modeling/meta_archs.py#L595-L614)

**机制**: 中心采样将正样本严格限制在 GT 段的中心区域, 半径为 `stride × center_sample_radius`

**WHY**:
- **减少边界模糊**: 动作段边界天然模糊, 边界 anchor 点容易学到矛盾回归目标
- **提高标签质量**: 中心区 anchor 点特征更纯净, 类别信噪比更高
- **对比 center_sample='none'**: 所有 GT 段内点都为正样本 → 回归训练不稳定

**验证**: 消融 A7 → `center_sample_radius=0.0`

### 7.2 num_bins=16

**代码**: [meta_archs.py:382-424](libs/modeling/meta_archs.py#L382-L424)

**机制**: Trident-head 不直接回归连续偏移量, 而是:
1. 中心偏移头: `2×(num_bins+1)=34` 通道
2. 左右边界头: 各 17 分类得分
3. 三路相加 → softmax → 期望值 → 连续偏移量

**WHY 16**:
- **离散化消噪**: 给回归加"分辨率限制", 梯度更稳定
- **精度-效率 trade-off**: 17 bin 覆盖全部范围, 16→32 倍增开销收益递减
- **与 FPN 联动**: 第 i 层 max_bin = `regression_range[i][1] / stride`

### 7.3 SGPBlock 的 5 分支设计

**代码**: [blocks.py:277-293](libs/modeling/blocks.py#L277-L293)

数学表达: `out = fc × phi + (convw + convkw) × psi + x`

| 分支 | 实现 | 建模含义 |
|------|------|---------|
| `psi` | depthwise_conv k3 | **即时局部特征**: 时间点周围的局部上下文 |
| `fc` | pointwise 1×1 | **逐通道变换**: 线性投影, 与 psi 逐元素相乘 |
| `convw` | depthwise_conv k3 | **标准窗口**: 标准感受野时序模式 |
| `convkw` | depthwise_conv `round((k+1)×win)` | **扩展窗口**: k 参数控制的扩展感受野 |
| `global_fc` | 1×1→avgpool→relu→1×1 | **全局通道门控 phi**: 基于全序列统计量调控 fc |

**WHY**:
- **多尺度融合**: `convw` + `convkw` 并行, 同时捕捉短时和长时依赖
- **门控机制**: `global_fc` 生成通道注意力 phi, 学会"哪些通道对当前输入更重要"
- **深度可分离**: 所有分支用 `groups=n_embd`, SGP 部分不到 3M 参数
- **残差连接**: `+ x` 确保即使 SGP 学习失败, 也不比普通卷积差

### 7.4 max_seq_len 必须被 32 整除

**代码**: [loc_generators.py:48](libs/modeling/loc_generators.py#L48)

```python
assert max_seq_len % scale_factor ** (fpn_levels - 1) == 0
```

FPN 6 层, stride=2 → 最低层分辨率 = 原始 / 2⁵ = 原始 / 32

实例: 1500→1472 (1472/32=46), 2304/32=72 (原生整除)

### 7.5 DIoU vs GIoU

**代码**: [losses.py:56-170](libs/modeling/losses.py#L56-L170)

**关键差异**:

| Loss | 公式 | 1D 特点 |
|------|------|---------|
| DIoU | `1 - IoU + ρ²/c²` | ρ=中心距离, c=最小外接段长度 | 有方向性引导 |
| GIoU | `1 - IoU + (C-U)/C` | C=最小外接段, U=并集 | **1D 中 C=U, 退化为 IoU** |

**WHY DIoU**:
- **中心距离惩罚**: IoU 相同的预测框, 偏移方向错误者得分更低
- **GIoU 退化为 IoU**: 1D 中 C=U → (C-U)/C=0, 丢失距离信息
- **收敛速度**: DIoU 通过中心距离直接引导预测框向 GT 中心靠拢

验证: 消融 A5

|------|---------|-------------|------|

### 8.4 混淆矩阵 Top 误分类

|---------|---------|------|------|

### 8.5 核心结论

1. **SGP 是最核心组件**: 移除 SGP → mAP 下降 ~15%。5 分支多尺度全局感知是 TriDet 的根基

2. **Trident-head 提供边界精度增益**: 移除后 mAP@0.7 下降 1.9%, 离散化改善精确定位

3. **三组件协同**: Trident-head 离散化 + SGP 多尺度特征 + DIoU 中心距离惩罚, 三者互补

4. **待完成 A3-A8**: 后续实验优先级: A3/A4 (SGP 超参) > A7 (采样半径) > A5 (DIoU验证) > A6 (FPN) > A8 (损失权重)

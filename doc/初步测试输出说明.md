## 二、脚本详细说明

### 2.1 test_modules.py — 模块 Shape 单元测试

| 项目 | 说明 |
|------|------|
| **用途** | 逐层验证 15 个模块的输入/输出 shape 正确性，覆盖从输入 `(B, 2048, T)` 到输出 `(segments, scores, labels)` 的完整数据流 |
| **用法** | `python evaluate/test_modules.py` |
| **输入** | 无外部输入（内部生成 dummy tensor: B=2, INPUT_DIM=2048, T=128） |
| **输出** | 终端打印 95 项测试的 PASS/FAIL 结果，exit code 0=全部通过 |
| **测试覆盖** | MaskedConv1D, LayerNorm, ConvBlock, SGPBlock, SGPBackbone, ConvBackbone, FPN1D, FPNIdentity, PointGenerator, ClsHead, RegHead(Trident), RegHead(Plain), DIoU/GIoU/Focal loss |
| **对应实验** | 基础测试，无实验依赖 |

### 2.2 common.py — 公共工具库

| 项目 | 说明 |
|------|------|
| **用途** | 提供 GT 加载、预测加载、配置覆写、mAP 解析、CSV 管理等共享函数，供其他脚本导入 |
| **导出函数** | `load_gt()` / `load_preds()` / `preds_by_video()` / `deep_set()` / `dump_yaml()` / `parse_maps()` / `load_ablation_csv()` / `save_ablation_csv()` / `compute_mAP_offline()` |
| **被引用** | `run_ablation_experiments.py` (deep_set, dump_yaml, parse_maps, CSV) / `analyze_predictions.py` (load_gt, load_preds, preds_by_video) |

### 2.3 run_ablation_experiments.py — 统一消融实验运行器

| 项目 | 说明 |
|------|------|
| **用途** | 合并了原 `run_ablation.py` / `run_all.py` / `run_training.py` / `train_all.py` / `do_all.py` 的全部功能 |
| **用法** | `--eval-only` (仅评估已有 ckpt)；`--train-only` (仅训练)；`--exp A1,A2,A3_w3` (指定实验)；`--all` (全部 A1-A8)；`--baseline` (仅基线)；`--start <exp_id>` (断点续跑) |
| **输入** | `configs/thumos_i3d.yaml` + 已有 ckpt 目录 + 训练队列定义 (硬编码) |
| **输出** | `evaluate/ablation_results.csv`，支持增量更新不覆盖已有结果 |
| **对应实验** | 全部 A1-A8 + baseline |
| **特点** | Phase 1/2 结构、已知结果硬编码复用、基线等效映射、临时文件输出避免 PIPE 死锁 |

### 2.4 analyze.py — 消融结果报告生成器

| 项目 | 说明 |
|------|------|
| **用途** | 读取 `ablation_results.csv`，生成 Markdown 报告 + 4 类图表 |
| **用法** | `python evaluate/analyze.py` |
| **输入** | `evaluate/ablation_results.csv`（由消融运行器生成） |
| **输出** | `evaluate/ablation_report.md` — 含汇总表、分项分析、组件排序、最优超参数推荐 |
| **输出图表** | `ablation_overview.png` (总览柱状图)、`ablation_core.png` (核心组件对比)、`ablation_a3.png/a4.png/a7.png/a8.png` (参数扫描折线图) |
| **对应实验** | A1-A8 消融结果（CSV 驱动，不直接接触模型/数据） |
| **ABLATION_SPEC** | 硬编码 8 组消融的标题、科学问题、参数映射和预期结论 |

### 2.5 analyze_predictions.py — 统一预测分析

| 项目 | 说明 |
|------|------|
| **用途** | 合并了原 `confusion_analysis.py` / `density_analysis.py` / `duration_analysis.py` / `analyze_results.py` / `run_full_analysis.py` 的分析功能 |
| **用法** | `--pred <pkl> --json <gt.json> --analysis confusion|density|duration|ablation|all` |
| **参数** | `--split` 数据集 split；`--tiou` tIoU 阈值；`--out` 输出路径前缀；`--ablation-dir` 消融摘要目录 |
| **输入** | 预测 pickle + THUMOS14 GT JSON + (可选) 消融 summary.json |
| **输出** | confusion_matrix.png / density_analysis.png + _hist.png / duration_analysis.png / ablation_comparison.png + map_vs_tiou.png |
| **对应实验** | 通用 — 任意模型预测均可；消融对比需 baseline/A1/A2 的 summary.json

## 四、configs/test/ 目录

| 配置文件 | 说明 | 使用状态 |
|----------|------|----------|
| `test_config.yaml` | 标准测试配置 (baseline 参数, 20 epochs) | **未被任何脚本引用** |
| `test_config2.yaml` | 与 test_config.yaml 内容相同 | **未被任何脚本引用** |
| `test_config3.yaml` | 与 test_config.yaml 内容相同 | **未被任何脚本引用** |
| `test_override.yaml` | 联合覆写测试 (use_trident_head=false, backbone_type=conv, k=3.0, center_sample_radius=0.0) | **未被任何脚本引用** |
| `abl_A1.yaml` | A1 消融配置 (use_trident_head=false) | **未被任何脚本引用**（evaluate/ 下另有 abl_A1.yaml） |
| `abl_A2.yaml` | A2 消融配置 (backbone_type=conv) | **未被任何脚本引用**（evaluate/ 下另有 abl_A2.yaml） |
| `abl_A3_w3.yaml` | A3_w3 消融配置 (n_sgp_win_size=3, 完整配置) | **未被任何脚本引用**（运行时会动态生成） |

> **结论**: `configs/test/` 目录下的所有配置文件均为早期测试用配置，当前没有任何 Python 脚本引用它们。消融实验运行器 `run_ablation_experiments.py` 在运行时会从 `configs/thumos_i3d.yaml` 动态覆写参数并生成临时配置到 `evaluate/abl_*.yaml`，不会读取此目录。建议在后续整理中评估是否需要保留。

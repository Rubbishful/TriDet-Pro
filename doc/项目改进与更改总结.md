# TriDet-Pro 项目改进与更改总结

> 生成时间：2026-07-04 | 分支：`dev-WangHaoxi`

---

## 一、核心改进概览

实现了**「视频 → OpenCV 帧提取 → 光流计算 → I3D 特征 (2048-dim) → TriDet 模型推理 → C NMS → 检测结果 TXT」**的端到端动作检测流水线。

| 指标 | 说明 |
|------|------|
| 模型 | TriDet (SGP backbone, Trident-head), 1598万参数 |
| 特征 | I3D RGB+Flow 拼接, 2048维 |
| 设备 | NVIDIA GeForce RTX 4060 Laptop GPU (8GB) |
| NMS | C 扩展后端 (`nms_1d_cpu`) + 纯 PyTorch 回退 |
| 输出 | TXT/csv（含起止时间、置信度、标签名）+ 摘要 |

## 三、流水线技术细节

### 3.1 处理流程

```
┌─────────┐    ┌──────────┐    ┌────────────┐    ┌───────────────┐    ┌────────┐
│ 视频.mp4 │───→│ OpenCV    │───→│ Farneback  │───→│ InceptionI3D  │───→│ TriDet │
│          │    │ 帧提取    │    │ 光流计算    │    │ RGB+Flow→2048 │    │ +C NMS │
└─────────┘    └──────────┘    └────────────┘    └───────────────┘    └────────┘
                                                                          │
                                                                  ┌───────┴───────┐
                                                                  │  result/*.txt │
                                                                  └───────────────┘
```

### 3.2 关键参数

| 参数 | 值 | 说明 |
|------|-----|------|
| 目标帧率 | 25 FPS | 从原始帧率重采样 |
| 帧尺寸 | 340×256 → center_crop 224×224 | I3D 标准输入 |
| 滑窗 | window=16帧, stride=4 | 相邻窗口重叠12帧 |
| 特征维度 | 2048 (RGB 1024 + Flow 1024) | Kinetics-400 预训练 |
| max_seq_len | 自适应 | 根据视频长度自动调整 |

### 3.3 动态序列长度适配

原始配置 `max_seq_len=128` 仅适用于短视频训练。流水线会根据实际特征长度自动计算所需的最小 `max_seq_len`（需被 `max_div_factor=32` 整除），确保任意长度视频均可推理。

### 3.4 NMS 后处理

- 优先使用 C 扩展 (`nms_1d_cpu`)，回退到纯 PyTorch 实现
- Soft NMS（高斯衰减, sigma=0.5）
- Multi-class NMS（逐类独立执行）
- 输出最多 2000 个检测段

## 五、使用方式

### 5.1 环境要求

```bash
conda activate id3
cd e:/xuexi/TriDet-Pro
```

- Python 3.9.25
- PyTorch 2.6.0+cu124
- CUDA 12.4
- opencv-python >= 4.5

### 5.2 单视频处理

```bash
python scripts/full_pipeline.py \
    --video id3shuju/shipin/01.mp4 \
    --config configs/id3_i3d.yaml \
    --ckpt epoch_039.pth.tar \
    --output_dir result
```

### 5.3 批量处理

```bash
python scripts/batch_pipeline.py \
    --video_dir ./input_videos \
    --output_dir ./pipeline_output \
    --checkpoint ./epoch_039.pth.tar \
    --device cuda:0
```

### 5.4 输出格式

- **TXT** (`result/{视频名}.txt`)：完整检测列表，按置信度降序排列
- **摘要** (`result/{视频名}_summary.txt`)：各类别统计 + Top-10 高置信度
- **CSV** (batch_pipeline)：批量处理的汇总结果

## 七、已修复的问题

1. **`total_mem` 属性错误**：PyTorch 中正确属性名为 `total_memory`，已在 `full_pipeline.py` 中修复
2. **`max_seq_len` 过小**：原始 128 无法处理长视频（如 01.mp4 的 1337 窗口），改为根据实际特征长度动态计算
3. **`module.` 前缀不兼容**：checkpoint 使用 DataParallel 保存，直接推理需去除 `module.` 前缀

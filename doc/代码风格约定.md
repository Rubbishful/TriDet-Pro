# 代码风格约定

## 语言

- 代码（变量名、函数名、类名、注释、docstring、日志、print）统一使用 **英文**
- 项目文档（`doc/` 下的 `.md`）可使用中文

## 引号

- Python 代码统一使用 **双引号** `"`
- YAML / JSON 使用标准格式，无需额外约束

## Docstring

- 统一 **Google 风格**，包含 `Args:` / `Returns:` / `Raises:` 分节
- 每个公共函数必须有 docstring

```python
def load_frames_from_video(video_path, target_fps=None, target_size=None):
    """Extract frames from a video file via OpenCV.

    Args:
        video_path: Path to the video file.
        target_fps: Target frame rate (None = use native FPS).
        target_size: (width, height) tuple, or None.

    Returns:
        frames: np.ndarray (T, H, W, 3), normalized to [-1, 1].
        actual_fps: Actual frame rate used for sampling.
    """
```

## Import

- 所有 import 放在**模块级别**，禁止在函数体内 lazy import
- 标准库 → 第三方库 → 项目内部模块，分组间空一行

```python
import argparse
import os

import numpy as np
import torch

from E2E.loader import load_frames_from_video
from libs.core import load_config
```

## 命名

- 变量/函数: `snake_case`
- 类: `CapWords` (`InceptionI3d`, `MaxPool3dSamePadding`)
- 常量: `UPPER_SNAKE_CASE` (`THUMOS14_LABEL_NAMES`)
- 私有成员: `_leading_underscore` (`self._output_channels`)
- 避免命名后缀变体（如 `_farneback`, `_opencv`），使用简洁名称

## 日志

- 统一英文前缀: `[INFO]`, `[WARN]`, `[ERROR]`, `[SKIP]`, `[OK]`

```python
print(f"[INFO] Loading RGB model: {rgb_model_path}")
print(f"[WARN] {vid}: {total_frames} frames < window size, skipping")
print(f"[ERROR] Video file not found: {video_path}")
```

## 路径处理

- 配置文件中的路径使用 **`./` 相对路径**，避免硬编码绝对路径（如 `D:/Code/...`）
- 脚本中对相对路径使用 `os.path.join(proj_root, path)` 显式解析，不使用 `os.chdir()`

## 模块组织

- 每个 `.py` 文件负责一个关注点，通过 `__init__.py` 导出公共 API
- 消除重复代码，共享逻辑抽取到独立模块
